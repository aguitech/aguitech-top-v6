# AGUITECH // TOP v6

Sitio oficial de AGUITECH — agencia de ingeniería, diseño y sistemas integrados.

**Estética:** White premium · Linear/Vercel style · Logo AGUITECH oficial
**Stack:** HTML5 · CSS custom · Vanilla JS (sin frameworks)
**Deploy:** GitHub Pages (main branch, root)

## 🗂️ Estructura

```
public/
├── index.html             # Hero con preview card + 4 stats + bento (7 verticales) + 6 proyectos
├── sobre-mi.html          # Bio founder + sticky card + 30 stack tags
├── servicios.html         # 7 verticales con anclas (#mkt #btl #web #ai #sistemas #diseno #3d)
├── experiencia.html       # Timeline interactivo 11 etapas (click para expandir)
├── proyectos.html         # 20+ casos reales de clientes top
├── contacto.html          # Form + sidebar sticky con canales directos
├── 404.html               # Página no encontrada con gradient
└── assets/
    ├── css/v6.css         # White palette: #fff + cyan #0084ff + serif italic
    ├── js/v6.js           # Typing effect, scroll-reveal, contadores, timeline toggle
    ├── img/logo.png       # Logo oficial AGUITECH (792x189, 20KB)
    └── img/favicon.ico    # Favicon multi-resolución
```

## ✨ Diferencias vs v5 (dark)

- **Fondo blanco premium** con paleta Linear/Vercel
- **Logo AGUITECH real** desde aguitech.com/images/logo.png
- **Hero preview card** estilo editor/Vercel con métricas
- **Bento cards** sin glows exuberantes (discreto, SaaS-style)
- **3 floating tags** alrededor de la preview card
- **Boxed form inputs** con border 1px en lugar de underline
- **Status bar** "Online · Disponible Q4 2026" arriba del hero
- **Sticky profile card** en sobre-mi.html con avatar gradient
- **Sticky aside** en contacto.html con canales clickeables

## 🎨 Identidad visual

- **Fondo:** `#ffffff` / `#fafafa` / `#f5f5f7` (3 niveles de grises)
- **Acento:** `#0084ff` (cyan) + `#0066ff` (azul)
- **Texto:** `#0a0a0f` (negro) / `#3a3a44` / `#6b6b78` / `#a0a0aa`
- **Tipografía:** `Inter` (sans 600/500) + `Instrument Serif` (italic display)
- **Botones:** radius 10–18px, no 100px (más sobrio)
- **Sombras:** 3 niveles (sm, md, lg), sutiles
